# Gatos de Néon: a BD

BD interativa de promoção do Gatos de Néon, um obby cooperativo para dois jogadores na Roblox.
Lê-se a descer a página, em português ou em inglês. A meio, o leitor ajuda os gatos a desligar o Capitão Gaiola (Captain Cage, em inglês).

Interactive promo comic for Gatos de Néon, a two-player co-op obby on Roblox. Available in Portuguese and English.

- Página: https://mmcp-s.github.io/gatos-de-neon/
- Um só ficheiro, `index.html`, com os desenhos em SVG, CSS e JavaScript. As letras (Fredoka e Nunito) vêm do Google Fonts.
- Para abrir já em inglês: https://mmcp-s.github.io/gatos-de-neon/#en

As ilustrações foram feitas para esta BD a partir do documento de design. Não são capturas do jogo.
